# 安全政策 / Security

本文件是本仓当前适用的安全政策。当前为研发阶段，尚无正式受支持发行版，不承诺固定响应或修复时限。

GitHub Private Vulnerability Reporting 需要在本仓公开发布窗口由仓库管理员启用并验证入口与通知后才能使用；在验证完成前，不提供未经确认的安全邮箱或假定可用的报告表单。公开发布前，受邀协作者使用已有私密协作渠道联系维护者。

不要在公开 Issue、PR 或讨论中提交漏洞细节、凭据和用户数据。渠道启用后，报告注明本仓名称、受影响版本/提交、影响和脱敏复现。支持范围与协调披露以统一政策为准；受支持社区版本安全修复不为商业订阅故意延迟。

This file is the current security policy for this repository. It is in development with no formally supported release or fixed response/remediation SLA. GitHub Private Vulnerability Reporting must be enabled and verified by this repository's administrator during the public release window; do not treat it as available before the entry and notifications are verified. Until then, invited collaborators use existing private collaboration channels; no unverified mailbox or reporting form is offered. Do not disclose vulnerabilities or secrets publicly. Once enabled, include this repository, the affected revision, impact and sanitized reproduction. Supported community fixes are not deliberately delayed for paid subscribers.
